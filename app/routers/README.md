# `app/routers/` —— FastAPI 接口路由与 RBAC 隔离规范

> **对应任务书要求**：《新能源汽车充电桩运营服务平台》第 2.2 / 3.4 节（5 类角色权限隔离与业务闭环接口）

---

## 一、 本层职责与编写模板

1. **标准骨架（直接参考 [`station.py`](<station.py>)）**：
   - 每个文件导出一个 `router = APIRouter(prefix="/api/<模块>", tags=["业务线X-..."])`；
   - 路由函数只负责：参数接收（Schema）→ 权限守卫 → 注入 `db: Session = Depends(get_db)` → 调用 `app/dao/` → 返回脱敏响应模型；
   - 禁止在路由里直接写 SQL 语句或吞掉数据库约束异常。
2. **挂载到主应用**：
   模块接口写完后，在 `app/main.py` 第 5 节的预留区添加 `app.include_router(...)`，即可在 `/docs` 中自动调试。
3. **接口文档规范**：
   每个 `@router.get/post/put/patch` 必须写明 `summary` 与 `response_model`，避免返回裸字典导致前端字段不统一。

## 二、 5 类角色 RBAC 权限矩阵（对接 `app/auth.py`）

根据任务书 2.2 节与会议要求，接口与视图查询必须按以下 **5 类角色** 严格隔离：

| 角色标识 | 角色名称 | 允许访问的核心接口与视图范围 | 越权红线（禁止操作） |
| :--- | :--- | :--- | :--- |
| `driver` | **普通车主** | 查找场站、扫码启停充电、查看**本人**订单/余额/优惠券、报障评价、申请电子发票 | 不可查看他人订单、全量手机号明文、工单或运营商结算单 |
| `ops` | **场站运维工程师** | 查看**分配给本人**的告警与维修工单、接单/到场/修复回填、提交设备变更与验收核对 | 不可查看车主支付流水或修改平台结算账单 |
| `settlement` | **客服与结算专员** | 处理异常充电退款与发票申诉、核对月度结算单与差异明细、办理开票与红冲 | 不可越权修改设备额定功率或审批营销活动 |
| `fleet` | **企业客户（车队）** | 批量开卡绑车、设置用车人与额度、查看**本企业**车队充电明细与月结账单、申请专属价格 | 严格隔离，不可查看其他企业车队及个人车主数据 |
| `admin` | **平台运营管理员** | 维护场站/桩/枪与运营商档案、配置分时计费规则、审核优惠活动、审批结算调账、全局看板 | 敏感数据导出受审计与脱敏策略约束 |

## 三、 5 条业务线路由模块与前缀约定

| 文件 | 路由前缀 | 负责业务线与主要接口分组 |
| :--- | :--- | :--- |
| [`station.py`](<station.py>) | `/api/stations` | **业务线 1（组长）**：运营商、场站、充电桩、充电枪档案管理，实时状态与状态变更日志视图 |
| `order.py` | `/api/orders` | **业务线 2（成员 2）**：分时计费规则管理、扫码启动/结束核价、费用明细、支付与退款记录 |
| `monitor.py` | `/api/monitor` | **业务线 3（成员 4）**：分钟级运行数据上报、告警列表与 SLA 升级、维修工单派发与闭环 |
| `user.py` | `/api/users` | **业务线 4（成员 3）**：车主档案与绑车、企业车队开卡与额度、优惠活动与发券/核销 |
| `settle.py` | `/api/settlements` | **业务线 5（成员 4）**：月度运营商结算生成、对账差异核查调账、开票与红冲 |
